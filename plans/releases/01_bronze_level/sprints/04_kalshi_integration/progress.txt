## Notes
- Kalshi uses RSA-PSS signatures (not simple API keys) - requires private key PEM file
- Signature = sign(timestamp_ms + HTTP_METHOD + path_without_query_params)
- Environment variables needed: KALSHI_API_KEY_ID, KALSHI_PRIVATE_KEY_PATH
- Maximum limit per request is 1000 records
- Cursor-based pagination (empty cursor = end of results)
