- [2026-01-28] polymarket_clob_client: Added PolymarketClobClient with L2 HMAC auth and cursor-based pagination
  - New file: src/prediction_data/bronze/polymarket/clob.py
  - CLOB_API_BASE_URL = https://clob.polymarket.com, endpoint GET /data/trades
  - L2 auth: HMAC-SHA256 signature over timestamp+method+path (query params excluded from signature)
  - 5 POLY_* headers: ADDRESS, SIGNATURE, TIMESTAMP, API_KEY, PASSPHRASE
  - Cursor-based pagination (next_cursor), not offset-based — no 10k limit
  - Configurable page_delay for rate limiting between paginated requests
  - ClobCredentials dataclass + load_clob_credentials() from Settings
  - Added CLOB settings to config.py: polygon_wallet_public_key, polygon_wallet_private_key, polymarket_builder_api_key, polymarket_builder_secret, polymarket_builder_passphrase
  - 17 unit tests in tests/test_polymarket_clob.py (HMAC signing, L2 headers, context manager, fetch page, pagination)
  - mypy clean, all 348 unit tests pass, no regressions
  - Note: PRD originally specified timestamp-based backward pagination, but actual CLOB API uses cursor-based pagination — implemented accordingly

- [2026-01-28] polymarket_trades_ingestion_update: Added CLOB-based trades ingestion for backfill
  - New async function ingest_trades_clob() in polymarket/ingest.py

  - Backfill CLI _ingest_one() now routes polymarket/trades to ingest_trades_clob() instead of ingest_trades()
  - mypy clean, all 348 unit tests pass, no regressions
