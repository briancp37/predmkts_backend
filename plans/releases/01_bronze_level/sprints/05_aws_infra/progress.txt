## Notes

### Container Usage
The container is designed to be run with command overrides from ECS task definitions:
```
docker run prediction-data:latest ingest polymarket-trades --dt 2026-01-28
docker run prediction-data:latest ingest kalshi-markets --dt 2026-01-28
```

Required environment variables for the container:
- BRONZE_BUCKET: S3 bucket name for Bronze storage
- AWS_REGION: AWS region (default: us-east-1)
- LOG_LEVEL: Logging level (default: INFO)
- KALSHI_API_KEY_ID: (optional) Kalshi API credentials
- KALSHI_PRIVATE_KEY_PATH: (optional) Path to Kalshi private key
