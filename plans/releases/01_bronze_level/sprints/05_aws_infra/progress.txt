### 2026-01-28: IAM Setup (iam_setup)
- Created CloudFormation template: infrastructure/iam-ecs-roles.yaml
- ECS Task Execution Role (prediction-data-execution-{env}):
  - Attaches AmazonECSTaskExecutionRolePolicy (ECR pull, CloudWatch Logs)
  - Optional Secrets Manager access for API credentials (prefix: prediction-data/*)
- ECS Task Role (prediction-data-task-{env}):
  - S3 access to Bronze bucket (ListBucket, GetObject, PutObject, DeleteObject)
  - CloudWatch Logs access for application logging
- Follows least-privilege principle throughout
- Parameterized for dev/staging/prod environments
- Exports role ARNs for use in ECS task definitions
- Deployment: `aws cloudformation deploy --template-file infrastructure/iam-ecs-roles.yaml --stack-name prediction-data-iam-roles --parameter-overrides Environment=dev BronzeBucketArn=arn:aws:s3:::prediction-bronze-dev --capabilities CAPABILITY_NAMED_IAM`

### 2026-01-28: ECS Cluster Setup (ecs_cluster)
- Created CloudFormation template: infrastructure/ecs-cluster.yaml
- ECS cluster named prediction-data-{env} with Container Insights enabled
- Task definition family: prediction-data-ingest-{env}
- Fargate launch type with configurable CPU (default 256 = 0.25 vCPU) and memory (default 512MB)
- CloudWatch log group: /ecs/prediction-data-{env} with configurable retention (default 30 days)
- Container configured with environment variables: BRONZE_BUCKET, AWS_REGION, LOG_LEVEL
- Parameterized for command overrides to run different ingestion commands
- Template validated with AWS CLI
- Example run command included in CloudFormation outputs
- Deployment:
  ```
  aws cloudformation deploy \
    --template-file infrastructure/ecs-cluster.yaml \
    --stack-name prediction-data-ecs \
    --parameter-overrides \
      Environment=dev \
      ECRImageUri=123456789012.dkr.ecr.us-east-1.amazonaws.com/prediction-data:latest \
      TaskExecutionRoleArn=<from-iam-stack> \
      TaskRoleArn=<from-iam-stack> \
      BronzeBucketName=prediction-bronze-dev
  ```

### 2026-01-28: EventBridge Schedules (eventbridge_schedules)
- Created CloudFormation template: infrastructure/eventbridge-schedules.yaml
- Uses AWS EventBridge Scheduler (modern approach vs EventBridge Rules)
- Created Schedule Group: prediction-data-{env} for organization
- Four schedules created:
  - polymarket-trades: Every 5 minutes (configurable)
  - kalshi-trades: Every 5 minutes (configurable)
  - polymarket-markets: Every 1 hour (configurable)
  - kalshi-markets: Every 1 hour (configurable)
- Timezone set to America/Chicago (configurable)
- IAM role for scheduler with least-privilege ECS RunTask permissions
- Each schedule targets ECS Fargate tasks with command overrides
- Retry policy: 2 retries with 5 min (trades) or 10 min (markets) max age
- Schedules can be enabled/disabled via ScheduleState parameter
- Template validated with AWS CLI
- Deployment:
  ```
  aws cloudformation deploy \
    --template-file infrastructure/eventbridge-schedules.yaml \
    --stack-name prediction-data-schedules \
    --parameter-overrides \
      Environment=dev \
      ECSClusterArn=<cluster-arn-from-ecs-stack> \
      TaskDefinitionArn=<task-def-arn-from-ecs-stack> \
      SubnetIds=subnet-xxx,subnet-yyy \
      SecurityGroupIds=sg-xxx \
    --capabilities CAPABILITY_NAMED_IAM
  ```

## Notes

### Container Usage
The container is designed to be run with command overrides from ECS task definitions:
```
docker run prediction-data:latest ingest polymarket-trades --dt 2026-01-28
docker run prediction-data:latest ingest kalshi-markets --dt 2026-01-28
```

Required environment variables for the container:
- BRONZE_BUCKET: S3 bucket name for Bronze storage
- AWS_REGION: AWS region (default: us-east-1)
- LOG_LEVEL: Logging level (default: INFO)
- KALSHI_API_KEY_ID: (optional) Kalshi API credentials
- KALSHI_PRIVATE_KEY_PATH: (optional) Path to Kalshi private key
