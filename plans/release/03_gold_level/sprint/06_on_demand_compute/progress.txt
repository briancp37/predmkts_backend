# Sprint Progress: On-Demand Compute
# Release: 03_gold_level
# Created: 2026-02-02

## Status: Complete

## Completed Tasks

- [x] snapshot_reconstruction: Created src/prediction_data/gold/on_demand.py with
  compute_wallet_snapshots() function. Accepts wallet, start_date, end_date.
  Checks S3 Gold for existing partitions (skips already-computed days).
  Replays wallet_position_ledger fills chronologically to rebuild position
  state at each day boundary. Joins with market_mark_daily for mark_price,
  position_value_usd, unrealized_pnl_usd. Handles edge cases: no trades in
  range (carries forward last known position via _read_initial_positions),
  missing marks (emits NaN values so position is still visible). Writes
  per-day partitions to S3 Gold using idempotent partition overwrite.
  Schema: wallet_position_snapshot_daily with 10 columns (day_utc, wallet,
  platform, market_id, outcome_id, qty, avg_cost, mark_price,
  position_value_usd, unrealized_pnl_usd).
- [x] Tests: 11 unit tests in tests/gold/test_on_demand.py covering replay
  logic (single fill, carry forward, initial positions, closed positions,
  missing marks, empty range, schema) and compute_wallet_snapshots
  (dry run, partial existing, no fills carry forward, all partitions exist).

- [x] caching: Added ClickHouse hot mirror loading to compute_wallet_snapshots().
  Partitions within DEFAULT_TTL_DAYS (90 days) are automatically inserted into
  the wallet_position_snapshot_daily ClickHouse table after S3 writes. Dates
  older than 90 days are skipped with a log message. Added skip_ch parameter
  to allow S3-only writes. Summary log emits partitions_computed,
  partitions_cached_s3, partitions_cached_ch, and rows_written. 3 new tests:
  test_ch_loading_for_recent_dates, test_ch_loading_skipped_for_old_dates,
  test_skip_ch_flag. Total: 14 tests passing.

- [x] cli: Added `prediction-data gold compute-snapshot` command in cli/gold.py.
  Accepts --wallet, --start-date, --end-date (all required). Supports --dry-run
  (compute without writing) and --skip-ch (S3 only, skip ClickHouse). Chunks
  large date ranges into configurable batches (--chunk-days, default 30).
  Prints progress: "Computing snapshots for wallet 0xABC... day 1-30/365".
  Delegates to on_demand.compute_wallet_snapshots() per chunk. mypy clean,
  178 tests passing.

- [x] testing: Added 5 CLI integration tests in TestComputeSnapshotCli class
  (tests/gold/test_on_demand.py): test_dry_run_end_to_end, test_skip_ch_flag,
  test_chunking_splits_large_range, test_progress_output, test_invalid_date_range.
  These mock compute_wallet_snapshots and get_settings to test CLI argument parsing,
  chunking behavior (45 days with chunk_days=30 → 2 calls), progress output formatting,
  flag propagation (dry_run, skip_ch), and invalid date range rejection.
  Total: 19 tests passing. All 927 non-integration tests pass. mypy clean
  (2 pre-existing unused-ignore errors in silver/).
