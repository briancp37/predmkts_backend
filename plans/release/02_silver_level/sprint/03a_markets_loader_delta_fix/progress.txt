What was done:
- Added `snapshot_type` property to `DiscoveredManifest` for easy access to manifest snapshot type.
- Added `select_snapshot_and_deltas()` function to `silver/discovery.py`:
  - Finds the latest snapshot manifest from a list of discovered manifests.
  - Collects any delta manifests generated after that snapshot.
  - Returns [snapshot, delta1, delta2, ...] for ordered loading.
  - Falls back to returning all manifests if no snapshots exist (pre-sprint-11 compat).

  - Discovers all Bronze polymarket/markets manifests.
  - Uses `select_snapshot_and_deltas()` to pick the right manifests.
  - Reads and loads records into `MarketsReferenceLookup` in order.
