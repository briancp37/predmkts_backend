## Completed Tasks

- [2026-01-30] markets_reference_loader: Built `MarketsReferenceLookup` class in
  `src/prediction_data/silver/polymarket/markets_reference.py`. Loads Bronze markets
  JSONL data, extracts `clobTokenIds` per market, and builds a long-form lookup table
  mapping `(asset_id) -> (market_id, side)`. Handles float-notation asset IDs (e.g.
  6.58e+76) by indexing both full-precision and float keys. Supports loading from
  raw JSONL bytes (gzipped or plain). 14 unit tests in `tests/test_markets_reference.py`
  all passing. mypy clean.

- [2026-01-30] trade_derivation_logic: Created `derive_trades.py` in
  `src/prediction_data/silver/polymarket/`. Implements `derive_trade()` and
  `derive_trades_batch()` functions. Identifies USDC vs conditional token side,
  resolves token to market/side via MarketsReferenceLookup, scales amounts by 1e6,
  computes price = usd_amount / token_amount, determines buy/sell direction.
  Handles edge cases: both-USDC, both-non-USDC, missing assets, zero amounts,
  invalid amounts, missing market lookup. 16 unit tests in
  `tests/test_derive_trades.py` all passing. mypy clean.
