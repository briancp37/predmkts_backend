## Status: In Progress

## Completed Tasks

- [2026-02-02] Compaction: Created `silver/maintenance.py` with `compact_table()` function
  - Scans partition file stats via `table.inspect.data_files()`
  - Identifies partitions needing compaction (>50 files, <64MB each)
  - Rewrites via `table.dynamic_partition_overwrite()` to consolidate into larger files
  - Returns `CompactionResult` dataclass with before/after stats
  - Added CLI command: `prediction-data silver compact --table platform/entity [--partition Y] [--dry-run]`
  - Full structured logging of compaction stats (files before/after, bytes saved, duration)
  - mypy strict + ruff clean on new code

- [2026-02-02] Snapshot Expiration: Added `expire_snapshots()` function to `silver/maintenance.py`
  - Uses PyIceberg `table.maintenance.expire_snapshots().older_than(cutoff).commit()` API
  - Configurable retention period via `older_than_days` param (default 7 days)
  - Protected snapshots (branch/tag heads) are never expired (handled by PyIceberg)
  - Returns `SnapshotExpirationResult` dataclass with before/after counts
  - Added CLI command: `prediction-data silver expire-snapshots --table platform/entity [--older-than-days 7] [--dry-run]`
  - Dry-run mode counts snapshots that would be expired without committing
  - Structured logging of expiration stats
  - mypy strict + ruff clean on new code
