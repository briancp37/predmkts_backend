# Sprint Progress: Iceberg Maintenance
# Release: 02_silver_level
# Created: 2026-01-30

## Status: In Progress

## Completed Tasks

- [2026-02-02] Compaction: Created `silver/maintenance.py` with `compact_table()` function
  - Scans partition file stats via `table.inspect.data_files()`
  - Identifies partitions needing compaction (>50 files, <64MB each)
  - Rewrites via `table.dynamic_partition_overwrite()` to consolidate into larger files
  - Returns `CompactionResult` dataclass with before/after stats
  - Added CLI command: `prediction-data silver compact --table platform/entity [--partition Y] [--dry-run]`
  - Full structured logging of compaction stats (files before/after, bytes saved, duration)
  - mypy strict + ruff clean on new code

- [2026-02-02] Snapshot Expiration: Added `expire_snapshots()` function to `silver/maintenance.py`
  - Uses PyIceberg `table.maintenance.expire_snapshots().older_than(cutoff).commit()` API
  - Configurable retention period via `older_than_days` param (default 7 days)
  - Protected snapshots (branch/tag heads) are never expired (handled by PyIceberg)
  - Returns `SnapshotExpirationResult` dataclass with before/after counts
  - Added CLI command: `prediction-data silver expire-snapshots --table platform/entity [--older-than-days 7] [--dry-run]`
  - Dry-run mode counts snapshots that would be expired without committing
  - Structured logging of expiration stats
  - mypy strict + ruff clean on new code

- [2026-02-02] Orphan Cleanup: Added `remove_orphans()` function to `silver/maintenance.py`
  - Lists all .parquet files under `{table_location}/data/` via S3 paginated listing
  - Compares against tracked files from `table.inspect.data_files()` metadata
  - Safety check: only deletes orphan files older than configurable threshold (default 7 days)
  - Returns `OrphanCleanupResult` dataclass with found/deleted counts and bytes
  - Added CLI command: `prediction-data silver remove-orphans --table platform/entity [--older-than-days 7] [--dry-run]`
  - Dry-run mode reports orphans without deleting
  - Structured logging of scan and cleanup stats
  - mypy strict + ruff clean on new code

- [2026-02-02] Testing: Added `tests/test_silver_maintenance.py` with 25 unit tests
  - TestNeedsCompaction: below threshold, large files, many small files triggers
  - TestParseS3Url: valid URL parsing, invalid URL raises MaintenanceError
  - TestCompactTable: unknown table raises, no files skipped, below threshold skipped,
    dry-run doesn't overwrite, compaction rewrites files, partition filter, nonexistent partition
  - TestExpireSnapshots: unknown table raises, dry-run counts without committing,
    commit + refresh flow, custom retention period
  - TestRemoveOrphans: unknown table raises, no orphans, detects orphans, dry-run doesn't delete,
    deletes orphan files, recent orphans not deleted (safety threshold)
  - TestResultDataclasses: field defaults for all three result types
  - All mocked (no S3/Iceberg dependencies); mypy strict + ruff clean
