## Blockers/Issues

## Notes

- This sprint was created after the first live Silver deployment revealed critical bugs
  and architectural gaps in the Bronze → Silver pipeline.
- Key issues discovered during deployment:
  1. decompress_jsonl used splitlines() which breaks on U+2028 Unicode line separators
     embedded in API data (e.g., Polymarket market question fields)
  2. Normalizers expected snake_case fields but Gamma API returns camelCase
  3. skip_quality_checks CLI flag was defined but never wired to the processor
  4. timestamp_range quality check rejects 97% of catalog entity records (full snapshots
     contain records with timestamps spanning years, not scoped to one day)
  5. Current ingestion model (one run_id per day, overwritten manifest) prevents
     continuous Silver processing — once Silver processes a manifest, it marks it done
     and ignores subsequent data added to the same run_id
