## Completed

### 2026-02-05: ClickHouse Query Utilities
- Created `src/prediction_data/api/clickhouse.py` with:
  - `get_clickhouse_client()`: Singleton pattern for ClickHouse client reuse
  - `execute_query()`: Async wrapper that runs queries in thread pool to avoid blocking
  - `execute_query_count()`: Convenience function for COUNT queries
  - `build_where_clause()`: Builds WHERE clauses with ILIKE support for search fields
  - `build_pagination()`: Builds LIMIT/OFFSET with max limit clamping
  - `build_order_by()`: Builds ORDER BY with field validation
  - `rows_to_models()`: Converts query results to Pydantic models
  - `ping()`: Async health check function
- Default query timeout: 10 seconds
- Thread pool with 4 workers for concurrent query execution
- All type checks pass (mypy)
- All 1441 tests pass (pytest)

### 2026-02-05: GET /markets Endpoint
- Implemented `get_markets()` service function in `src/prediction_data/api/markets/service.py`:
  - Queries ClickHouse dim_market table with LEFT JOIN to dim_event for category filtering
  - Queries dim_outcome for outcome details per market
  - Falls back to parsing tokens JSON if outcomes not in dim_outcome
  - Supports filters: category (exact match via event), search (ILIKE on question/description), resolved (boolean)
  - Returns paginated results ordered by updated_at DESC
  - Helper function `_parse_tokens_to_outcomes()` for extracting outcomes from tokens JSON
- Implemented `GET /markets` endpoint in `src/prediction_data/api/markets/router.py`:
  - Query params: category, search, resolved, limit (1-500, default 50), offset
  - Returns MarketListResponse with items, total, page, limit
  - Full OpenAPI documentation with descriptions
- All type checks pass (mypy)
- All 1441 tests pass (pytest)
- Note: totalVolume, liquidity, currentPrice, endDate, imageUrl fields return default values
  (0.0, 0.5, None) as they are not in current ClickHouse dim_market schema. Will be populated
  when market_mark_daily integration is added or CLOB API client is implemented.

### 2026-02-05: GET /markets/{id} Endpoint
- Implemented `get_market_by_id()` service function in `src/prediction_data/api/markets/service.py`:
  - Queries ClickHouse dim_market with flexible ID matching (platform_market_id OR market_slug)
  - LEFT JOIN to dim_event for category data
  - Queries dim_outcome for outcome details
  - Falls back to parsing tokens JSON if outcomes not in dim_outcome
  - Returns market dict formatted for MarketResponse, or None if not found
- Implemented `GET /markets/{id}` endpoint in `src/prediction_data/api/markets/router.py`:
  - Path parameter: market_id (can be internal ID, polymarketId, or slug)
  - Returns MarketResponse with full outcome details
  - Returns 404 HTTPException if market not found
  - Full OpenAPI documentation with descriptions
- All type checks pass (mypy)
- All 1441 tests pass (pytest)
- Note: CLOB integration (include_clob param) deferred to CLOB API Client implementation
