## Overview
Migrate PostgreSQL user database from local docker-compose to Supabase free tier for production deployment. This enables $0/month hosting for user data (vs ~$15/month for AWS RDS) while maintaining full compatibility with local development.

## Key Decisions
- Use Supabase free tier (500MB, sufficient for 100k+ users)
- Keep docker-compose for local development (DATABASE_MODE=local)
- Use Supabase pooler (PgBouncer) for production (DATABASE_MODE=supabase)
- Direct connection (port 5432) only for DDL/migrations
- Pooled connection (port 6543) for all application queries

## Notes
- Supabase free tier pauses after 1 week of inactivity (~10s cold start on wake)
- Free tier allows ~60 concurrent connections (pooler helps manage this)
- Supabase is standard Postgres - no code changes needed, only connection config
- Consider upgrading to Pro ($25/mo) if usage exceeds free tier limits
