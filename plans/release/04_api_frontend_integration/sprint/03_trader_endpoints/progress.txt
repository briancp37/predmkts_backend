  - Added GET /traders endpoint in router.py with query params: search, sortBy, sortOrder, limit, offset
  - Implemented get_traders() in service.py with ClickHouse query
  - Joins dim_wallet with aggregated wallet_pnl_daily for PnL and trade statistics
  - Search filters by wallet address prefix using ILIKE
  - Sort options: totalPnl, totalTrades, winRate (smartScore uses totalPnl as proxy until computed)

  - All types pass mypy, all tests pass

- [2026-02-05] GET /traders/{address} Endpoint - Implemented single trader detail with positions
  - Added GET /traders/{address} endpoint in router.py with path parameter for wallet address
  - Implemented get_trader_by_address() in service.py with ClickHouse queries
  - Normalizes wallet address to lowercase for consistent lookups
  - Queries dim_wallet joined with aggregated wallet_pnl_daily for trader metadata and PnL
  - Queries wallet_position_state FINAL for current open positions (qty != 0)
  - Joins positions with dim_market for market question and dim_outcome for outcome names
  - Joins with market_mark_daily for current prices to calculate unrealized PnL
  - Positions ordered by absolute value (cost basis) descending
  - Calculates win rate from wins/(wins+losses) stored in wallet_pnl_daily
  - Returns TraderDetailResponse with positions list, tradeCount, and winRate
  - Returns 404 HTTPException if trader not found
  - All types pass mypy, all tests pass

- [2026-02-05] GET /traders/{address}/trades Endpoint - Implemented trader trades listing
  - Added GET /traders/{address}/trades endpoint in router.py
  - Implemented get_trader_trades() in service.py with ClickHouse query
  - Accepts query params: limit (default 100, max 1000), offset, startDate, endDate, marketId
  - Queries wallet_position_ledger for trader's transactions
  - Joins with dim_market for market question and dim_outcome for outcome names
  - Returns trade data: id, traderAddress, marketId, marketQuestion, outcomeId, outcomeName
  - Includes side (BUY/SELL derived from qty_delta sign), price, quantity, usdValue (qty * price)
  - Includes fees and realized PnL (only included if non-zero, indicating closing trade)
  - Timestamp formatted as ISO 8601 string
  - Orders by timestamp DESC (newest first)
  - Returns TradeListResponse with pagination (items, total, page, limit)
  - All types pass mypy, all tests pass

- [2026-02-05] Leaderboard Router Setup + GET /leaderboard Endpoint - Implemented PnL leaderboard
  - Added GET /traders/leaderboard endpoint in traders/router.py (added to existing traders router)
  - Implemented get_leaderboard() in traders/service.py with ClickHouse query
  - Accepts query params: period (Literal['1d', '7d', '30d', 'all']), limit (default 100, max 500)
  - Queries wallet_pnl_daily with date filtering based on period:
    - '1d': today() only
    - '7d': today() - 7 days
    - '30d': today() - 30 days
    - 'all': all-time (no filter)
  - Aggregates realized_pnl_usd, trades_count, wins, losses per wallet
  - Calculates win rate as wins / (wins + losses) * 100
  - Orders by PnL DESC and assigns 1-indexed ranks
  - Returns LeaderboardResponse with period, entries list, and generatedAt timestamp
  - Schemas already existed (LeaderboardEntry, LeaderboardResponse, LeaderboardFilters)
  - Endpoint placed before /{address} to avoid path conflict
  - All types pass mypy, all tests pass

- [2026-02-05] Trades Router Setup + GET /trades/smart + GET /trades/whales - Implemented global trades endpoints
  - Created src/prediction_data/api/trades/ directory with __init__.py, router.py, service.py, schemas.py
  - Registered trades router in api/main.py with prefix /api/v1/trades and 'trades' tag
  - Schemas re-export SmartTradeResponse, WhaleTradeResponse from traders/schemas.py (already defined)
  - GET /trades/smart endpoint:
    - Accepts query params: minScore (0-100, default 70), minAmount (optional USD filter), limit (1-200, default 50)
    - Queries wallet_position_ledger joined with computed smart scores
    - Smart score computed as PnL-based rank percentile (top PnL traders get higher scores)
    - Filters to traders with smartScore >= minScore
    - Orders by timestamp DESC (newest trades first)
    - Returns list of SmartTradeResponse with trade details + smartScore
  - GET /trades/whales endpoint:
    - Accepts query params: minAmount (USD, default 10000), limit (1-200, default 50)
    - Queries wallet_position_ledger for trades with USD value >= minAmount
    - Joins with wallet_position_state to get trader's total portfolio value
    - Orders by timestamp DESC
    - Returns list of WhaleTradeResponse with trade details + totalWalletValue
  - All types pass mypy, all 1441 tests pass

- [2026-02-05] Smart Score Computation + GET /traders/smart-scores Endpoint - Full implementation
  - Created src/prediction_data/api/smart_score.py with scoring functions
  - Smart score algorithm based on 4 weighted components (0-100 final score):
    - Accuracy (30%): Win rate on closed positions (0-30 points)
    - Consistency (25%): Trade regularity over lookback period (0-25 points)
    - Sizing (25%): Volume traded on log scale (0-25 points)
    - Timing (20%): ROI efficiency (-20 to +20 points)
  - Implemented compute_smart_score(wallet_address, lookback_days) for single wallet
  - Implemented compute_smart_scores_batch() for bulk computation with filtering
  - Minimum 5 trades required for meaningful score (returns 0 otherwise)
  - Added GET /traders/smart-scores endpoint in traders/router.py:
    - Query params: minScore (0-100), limit (1-500, default 100), timeWindow (7d, 30d, 90d, all)
    - Returns SmartScoreListResponse with items, timeWindow, generatedAt
    - Each item contains address, smartScore, and components breakdown
  - Added SmartScoreListResponse and SmartScoreFilters schemas
  - Scores computed on-demand from wallet_pnl_daily (no pre-computation yet)
  - All types pass mypy, all 1441 tests pass
