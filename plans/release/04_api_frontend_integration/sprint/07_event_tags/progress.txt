## Notes

This sprint implements end-to-end tag support:
1. Bronze → Silver → Gold pipeline for event tags
2. API endpoints for tag listing and filtering
3. User-saved tag templates (PostgreSQL)
4. Frontend components for tag filtering and template management

Key decisions made:
- Tags schema: Using Array(String) for simplicity (just tag labels)
- Tag labels extracted from Bronze objects with {label, slug, ...} structure
- Missing tags return None (not empty array) for storage efficiency

Dependencies:
- Requires dim_event populated in ClickHouse
- Requires user auth for tag templates
