## Notes

- The existing `web/src/components/ui/price-chart.tsx` uses `lightweight-charts` library.
  The new event PriceChart uses Recharts as specified in the PRD for consistency with
  other chart components (VolumeChart, etc).
- The PriceChart accepts a `tokenId` prop which comes from `EventMarketOutcome.tokenId`
  in the event response.
- TimeRangeSelector can be composed with PriceChart - use `useTimeseriesIntervalFromUrl()`
  to get the interval from URL and pass to PriceChart's `interval` prop.
- Next task should be volume_overlay, orderbook_component, or chart_loading_states.
- **API limitation**: The Polymarket CLOB `/prices-history` endpoint only returns `{t, p}`
  (timestamp, price) data points. True OHLC candlestick data or per-period volume would
  require either aggregating from trade data or waiting for a candlestick API endpoint.
