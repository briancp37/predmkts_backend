# Sprint 07: Expandable Market Accordion

## Overview
Implement Polymarket-style expandable market rows where each market in an event
can be clicked to expand inline, showing Order Book, Graph, and Resolution tabs.
This replaces the simple OutcomesList with an interactive accordion pattern.

## Reference
- Polymarket event page: https://polymarket.com/event/who-will-trump-nominate-as-fed-chair
- Key UX: Click on candidate row -> expands with Order Book | Graph | Resolution tabs

## Dependencies
- Sprint 00: Proxy layer (useOrderbook, useTimeseries, useMarketPrice hooks)
- Sprint 04: PriceChart, OrderBook, TimeRangeSelector components
- Sprint 02: ResolutionRules, OutcomeCard components
