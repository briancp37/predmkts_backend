### Architecture Notes for Next Developer

The proxy client is designed for extensibility. To add a new proxy endpoint:

1. Add endpoint method to `client.py` using `get_clob()`, `get_data()`, or `get_gamma()`
2. Add response schema to `schemas.py`
3. Add route to `router.py` with appropriate rate limiting

Cache TTLs should be configured per-endpoint based on data volatility:
- Order book: 5s (very volatile)
- Trades: 30s
- Market info: 10s
- Timeseries: varies by interval (30s for 1m, 5m for 1h, 1h for 1d)
- Top holders: 5m (changes slowly)

The circuit breaker will automatically protect against cascading failures.
When a circuit opens, requests fail fast and return an error to the client.
After 30s recovery timeout, the circuit enters half-open state to test recovery.
