## Architecture Decision

Using **Polymarket API Proxy** pattern:
- Frontend calls our FastAPI backend
- Backend proxies to Polymarket CLOB/Data APIs
- Caching layer (Redis or in-memory) for rate limiting
- Real-time data without building pipelines
